## 🚀 Featured project

### 🎧 [MoodDJ: an agentic music recommender](https://github.com/AishNiroula/mooddj-agentic-music-recommender)

Type something like *"songs for late-night studying"* or *"upbeat workout playlist but no country"* and get a small, explained playlist back. I took a static, parameter-driven recommender and wrapped it in a **plan → act → verify** agent.

| | |
|---|---|
| **Agent** | Turns free-form text into a structured user profile. Uses **Claude** when an API key is set and falls back to a deterministic rules parser if anything fails. |
| **Retrieval** | Cosine-similarity probe over song feature vectors, plus weighted scoring and ranking. |
| **Guardrails** | Input validation, prompt-injection pattern checks, and output checks (duplicates, avoided genres). |
| **Evals** | A 10-case structured eval suite (10/10 passing) and a 37-test pytest suite, including fallback-on-failure. |

**What I learned:** ranking systems are policy choices. Sweeping the scoring weights flipped the top result from a calm lo-fi track to a high-energy one. Guardrails and evals didn't make the system smarter, but they made it possible to know *when* it was wrong.
